# 知识库同步发布检查表

> **状态**：当前发布附表（2026-08-05）  
> 用途：每次正式发版或生产变更窗口前由发布负责人勾选；与 `kb-sync` / 文档 MR 联动。主发布判定以 [发布 Runbook](release-runbook.md) 为准。

## 变更前评估

- [ ] 已阅读本次 release 的 changelog / PR 列表，识别**是否影响**：接口契约、错误码、队列名、表结构、业务流程状态机、配置项说明
- [ ] 若影响上述任一项：已列出需更新的 **architecture / process / runbook** 文档路径（或已提交 MR）
- [ ] `documents/kb/**` 相关 MR 已获得 **CODEOWNERS** 要求的 Approve

## 发版流水线（CI）

- [ ] **kb-sync** Job 已纳入本次发版流水线且 **Variables/Secrets** 指向**目标环境**（dev/staging/prod 勿混用）
- [ ] 本次发版 Git tag 使用 **`vMAJOR.MINOR.PATCH`** 格式（例 `v2.4.0`）；若项目实际版本策略不同，已记录豁免与原因
- [ ] 发版完成后 **kb-sync 成功**（或按门禁策略已记录豁免与审批人）

## 发版后验证

- [ ] 目标数据集中新增/更新文档状态为 **已完成**（或队列已消费完毕）
- [ ] 抽样 1～2 条对话检索，确认新知识可被命中
- [ ] 若本次为**事故热修**：已在 **24h SLA** 内创建/更新 incident 卡或 PR（与 FR-04 一致）
