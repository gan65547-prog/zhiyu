# AI 工作台发布 Runbook 与验收清单

> **状态**：当前发布执行基线（2026-08-05）  
> 用途：每次生产发布按本清单执行，确保“可发布、可验证、可回滚”。不依赖任何日期化上线计划。

> **发布门禁**：[release/release-profile.json](../../release/release-profile.json) 定义当前版本必测能力；[release/README.md](../../release/README.md) 定义证据和状态机。未经当前 HEAD 证据验证的候选不得创建 release tag。

---

## 1. 角色与沟通

- 发布指挥官（1人）：统一下达开始/暂停/回滚指令。
- 执行人：后端、前端、DevOps、QA 各 1 人。
- 观察人：业务代表或产品负责人 1 人。
- 沟通频道：单一群组（避免多通道信息分叉）。

---

## 2. 上线前 30 分钟检查（Preflight）

### 2.1 变更与版本
- [ ] 本次发布版本号/tag 已确认。
- [ ] 变更列表已确认，无未评审高风险改动。
- [ ] 回滚目标版本可用（镜像/包/配置齐全）。
- [ ] 当前 P0/P1 缺陷已评估；任何未豁免的安全、隔离或数据损坏风险均为 No-Go。

### 2.2 环境与依赖
- [ ] PostgreSQL 可连接，连接数在安全水位。
- [ ] Redis 可连接，读写正常。
- [ ] Qdrant 健康检查通过。
- [ ] 域名、证书、反向代理配置正确。
- [ ] 环境变量已注入，敏感信息不在明文文档中。
- [ ] 生产环境已设置非默认的密钥、数据库凭据、内部运维密钥与来源白名单。

### 2.3 备份确认
- [ ] 发布前即时备份已完成（DB + 向量库 + 核心配置）。
- [ ] 备份文件已校验可读，存储路径已记录。
- [ ] 恢复步骤责任人已到位。

---

## 3. 发布执行步骤（T 日）

## 步骤 1：进入发布窗口
- [ ] 通知所有相关方“开始发布”。
- [ ] 冻结非必要操作（避免并发变更）。

## 步骤 2：部署后端
- [ ] 拉取目标版本并校验版本号。
- [ ] 安装/同步依赖。
- [ ] 执行数据库迁移（如有）。
- [ ] 重启后端服务并检查健康检查接口。

## 步骤 3：部署前端
- [ ] 构建前端产物。
- [ ] 发布静态资源并刷新反向代理缓存。
- [ ] 打开首页确认静态资源加载正常。

## 步骤 4：依赖服务验证
- [ ] Qdrant 集合可访问，写入/查询正常。
- [ ] Redis 缓存读写正常。
- [ ] PostgreSQL 读写与索引查询正常。

---

## 4. 冒烟验收（上线后 15 分钟内）

### 4.1 核心业务链路
- [ ] 用户登录成功。
- [ ] 进入目标工作空间成功。
- [ ] 上传文档成功，状态进入处理并最终完成。
- [ ] 文档分段数量大于 0。
- [ ] 发起问答成功，返回包含检索信息的回答。

### 4.2 权限与隔离
- [ ] 非授权用户无法访问他人工作空间数据。
- [ ] 多租户数据隔离验证通过。
- [ ] 文档和会话资源的越权访问回归通过。

### 4.3 稳定性观察
- [ ] 5xx 错误率在阈值内。
- [ ] API 延迟在阈值内。
- [ ] CPU/内存/磁盘无异常突增。

---

## 5. 回滚策略（触发即执行）

## 触发条件（任一满足）
- 连续 5 分钟核心接口错误率超阈值。
- 核心链路（上传、检索、问答）不可用。
- 数据一致性风险无法在 10 分钟内修复。

## 回滚步骤
- [ ] 宣布回滚并冻结新请求入口（若可控）。
- [ ] 应用层回滚到上一稳定版本。
- [ ] 若涉及迁移，按预案执行数据回滚或前向修复。
- [ ] 校验数据库迁移状态（是否需要 downgrade / 标记修复迁移）。
- [ ] 校验向量数据一致性（集合数量、分段数量、索引状态）。
- [ ] 清理或失效高风险缓存键，避免旧缓存污染新版本。
- [ ] 恢复后执行最小冒烟测试（登录、上传、问答）。
- [ ] 对外同步“回滚完成+后续计划”。

---

## 6. 监控与告警验收

- [ ] 已接入服务存活告警（backend/postgres/redis/qdrant）。
- [ ] 已接入错误率告警（5xx、超时）。
- [ ] 已接入资源告警（CPU/内存/磁盘）。
- [ ] 告警通知通道实测可达（邮件/IM 至少一种）。
- [ ] 值班人和升级联系人清晰可联系。

---

## 7. 上线完成判定（Go-Live Sign-off）

满足以下全部条件可判定上线完成：

- [ ] 冒烟验收全部通过。
- [ ] 发布前备份、恢复演练和回滚预案均有本次可追溯证据。
- [ ] 观察窗口（建议 2 小时）无重大告警。
- [ ] 无 P0/P1 新增缺陷。
- [ ] 发布记录、版本号、执行人、时间戳已归档。
