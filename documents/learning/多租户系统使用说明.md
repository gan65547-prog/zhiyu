# 多租户系统使用说明

## 一、快速开始

### 1.1 初始化数据库和种子数据

首先运行数据库初始化和种子数据脚本：

```bash
# 进入项目目录
cd /Users/gan/Documents/ganfy/enterprise-rag-v2

# 初始化数据库（创建表结构和默认数据）
python scripts/init_db.py

# 生成测试种子数据（多个租户、用户、工作空间）
python scripts/seed_data.py
```

### 1.2 启动服务

```bash
# 启动后端服务
python main.py

# 启动前端服务（新开终端）
cd frontend
npm run dev
```

### 4.3 工作空间管理

#### 4.3.1 查看工作空间列表

点击"工作空间"，你会看到该租户下的所有工作空间：
- 产品部
- 研发部

#### 4.3.2 创建新工作空间

1. 点击"创建工作空间"按钮
2. 输入工作空间名称和描述
3. 点击"创建"

#### 4.3.3 管理工作空间成员

在工作空间列表中，点击"成员管理"按钮：

**成员管理功能**：
1. **查看成员列表**：看到工作空间中的所有成员及其角色
2. **添加成员**：
   - 点击"添加成员"
   - 输入用户ID（需要先有这个用户）
   - 选择角色（owner/admin/member/viewer）
   - 点击"添加"
3. **编辑成员角色**：
   - 点击"编辑角色"
   - 选择新的角色
   - 点击"保存"
4. **移除成员**：
   - 点击"移除"
   - 确认删除

#### 4.3.4 切换工作空间

点击"切换"按钮，可以切换当前工作空间。

#### 4.3.5 删除工作空间

点击"删除"按钮，可以删除工作空间（默认工作空间不能删除）。

### 4.4 知识库管理

作为 ADMIN/OWNER，你可以：
- **创建知识库**：点击"新建知识库"
- **编辑知识库**：点击知识库卡片的"编辑"
- **删除知识库**：点击知识库卡片的"删除"
- **上传文档**：进入知识库后上传文档
- **删除文档**：删除不需要的文档

## 七、常见问题

### 7.1 如何知道我在当前工作空间的角色？

目前系统还没有在前端直接显示角色的功能，你可以：
1. 通过尝试操作来判断（比如能否删除知识库）
2. 或者让工作空间的 OWNER/ADMIN 在成员管理页面查看

### 7.2 一个用户可以在不同工作空间有不同角色吗？

可以！这正是系统设计的亮点。例如：
- 李四在"产品部"是 ADMIN
- 李四在"研发部"是 OWNER

### 7.3 如何创建新用户？

目前系统还没有用户注册界面，需要：
1. 超级管理员直接在数据库创建用户
2. 或者通过API创建用户

### 7.4 忘记密码怎么办？

目前系统没有找回密码功能，需要：
1. 超级管理员在数据库重置密码
2. 或者通过API修改密码
