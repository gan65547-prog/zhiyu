# AI 工作台浏览器回归清单

## 目的

这份清单用于把一次性真实浏览器检查固化为可重复的人工回归基线。API 回归脚本负责业务状态和异步任务；本清单负责登录、路由、页面级错误、关键按钮、弹窗、空态和跨页面跳转。

当前项目已接入 Playwright；本文件是本地真实浏览器回归和手动 CI 工作流共用的验收契约。GitHub Runner 尚未实际触发，因此不把本地结果等同于外部 Runner 验收。

## 环境与前置条件

- 前端：由 Playwright `webServer` 启动，默认 `http://127.0.0.1:3001`
- API：`http://127.0.0.1:8001`
- 测试账号：使用临时回归账号，不把密码写入仓库
- 启动前端、API、Redis、Qdrant 和 Celery worker；worker 必须使用与 API 相同的数据库、broker/result backend，并在宿主机环境显式设置 `QDRANT_URL=http://127.0.0.1:6333`
- 每个用例结束后记录：URL、页面标题/主标题、关键断言、控制台错误、网络失败、截图路径和结果

## 跨页面闭环

### C-01 素材到知识库

1. `/assets` 添加粘贴文本或固定公网 URL，并绑定知识库。
2. 等待素材变为 `已就绪`，检查文档为 `COMPLETED`、分段数大于 0。
3. 打开阅读台，确认正文可见。
4. `/chat` 选择该知识库，提问可由内部证据回答；模型不可用时也必须显示明确失败/降级文案。

### C-02 研究到内容

1. `/research` 创建研究，绑定内部知识库或固定公网来源。
2. 验证 `completed`、`cancelled`、`failed` 三种终态的中文状态、进度和操作入口。
3. 打开完成报告，检查结论、证据 ID、来源地址和引用正文。
4. 审核通过并生成内容草稿，进入 `/content` 验证草稿状态。

### C-03 内容到数据复盘

1. `/content` 审核草稿并通过工作台弹窗记录人工发布。
2. `/platform-data` 录入或批量导入至少两次指标快照。
3. 检查平台汇总、趋势、排行、CTR 和最近快照表。
4. 返回内容中心或数据中心，确认指标和复盘建议读取同一发布记录。

## 异常态与问题分级

| 等级 | 定义 | 验收处理 |
| --- | --- | --- |
| P0 | 登录、主导航、核心页面打不开；数据错乱导致用户无法继续；关键流程卡死或误报成功 | 阻断验收，必须修复 |
| P1 | 核心流程可绕过但失败态、重试、异步终态或真实数据边界不完整；外部平台连接器缺失 | 阶段验收必须登记，生产前关闭或明确豁免 |
| P2 | 视觉细节、响应式、无障碍、性能、截图差异和非关键空态体验问题 | 进入迭代队列，不阻断当前开发态验收 |

每条问题至少记录：页面/路由、复现步骤、预期、实际、环境、严重级别、截图或日志证据、责任模块、修复状态和复测日期。
