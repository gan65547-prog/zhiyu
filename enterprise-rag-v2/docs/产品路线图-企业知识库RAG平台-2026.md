## 三、Phase 1：核心体验提升（现在 → v2.5，4-6 周）

### 3.1 深度文档解析（对标 RAGFlow）

**现状：** 仅使用 PyPDF2、python-docx 等基础库做文本提取，不支持表格、图表、版面还原。

**目标：** 文档理解准确率从当前水平提升到 90%+

| 任务 | 优先级 | 工作量 | 说明 |
|:----|:------:|:------:|------|
| 集成 Docling / Marker / MinerU | P0 | 2-3 天 | 开源文档解析引擎，支持 PDF 版面还原、表格提取 |
| PDF 表格提取 + Markdown 输出 | P0 | 2 天 | 表格数据不可丢失 |
| 分块策略优化（语义分块） | P1 | 2 天 | 按段落/语义边界分块，替代固定大小分块 |
| 文档 OCR 支持（扫描件） | P2 | 3 天 | 集成 PaddleOCR / EasyOCR |
| 多列/复杂版面解析 | P2 | 2 天 | 两栏/三栏排版 |

**推荐方案：**
```python
# 对比两个方向
# 方案 A：MinerU（PDF-Extract-Kit）- 中文场景最强
# 方案 B：Docling（IBM）- 多格式统一，更轻量
# 建议：MinerU 为主，Docling 为 fallback
```

### 3.2 混合检索优化

**现状：** 基于 Qdrant 向量检索 + SimpleReranker。

**目标：** 检索召回率从当前水平提升到 90%+

| 任务 | 优先级 | 工作量 | 说明 |
|:----|:------:|:------:|------|
| BM25 + 向量混合检索 | P0 | 2 天 | Qdrant 支持 hybrid search |
| 接入更好的 Reranker | P1 | 1 天 | BGE-Reranker / Cohere Rerank |
| 检索参数自动调优 | P2 | 2 天 | chunk_size, top_k, score_threshold |
| 检索结果解释（溯源） | P1 | 2 天 | 显示匹配原文片段 + 匹配分 |

### 3.3 多 LLM 接入

**现状：** 支持 Ollama 本地 + DeepSeek API。

**目标：** 支持主流国产模型一键切换

| 任务 | 优先级 | 工作量 | 说明 |
|:----|:------:|:------:|------|
| 通用 OpenAI API 兼容层 | P0 | 1 天 | 兼容所有 OpenAI API 格式的模型 |
| 添加 Qwen（通义千问） | P1 | 0.5 天 | 国产模型接入 |
| 添加 DeepSeek 原生 SDK | P1 | 0.5 天 | 现有 DeepSeek 适配改进 |
| 模型动态切换 UI | P1 | 2 天 | 前端可选择模型 |

### 3.4 知识库 UI 重构

**现状：** 基础功能可用，但与 Notion AI、飞书知识库相比差距大。

**目标：** 交互流畅、信息层级清晰

| 任务 | 优先级 | 工作量 | 说明 |
|:----|:------:|:------:|------|
| 知识库首页（概览仪表盘） | P0 | 3 天 | 文档统计、最近使用、搜索入口 |
| 文档预览优化 | P1 | 2 天 | 内联预览 + 高亮匹配片段 |
| 拖拽上传/文件夹组织 | P1 | 2 天 | 文件管理体验提升 |
| 批量操作（删除/移动/重处理） | P1 | 2 天 | 提升管理效率 |
| 搜索体验优化 | P0 | 2 天 | 全局搜索 + 搜索建议 + 结果高亮 |

### Phase 1 验收标准

```
☐ PDF 表格内容可被正确检索
☐ 检索召回到率 > 90%（在测试集上）
☐ 支持至少 3 个 LLM 切换（Ollama / DeepSeek / Qwen）
☐ 知识库首页可用
☐ 全局搜索可用，结果可溯源
```

## 八、风险与缓解

| 风险 | 可能性 | 影响 | 缓解措施 |
|:----|:------:|:----:|---------|
| 文档解析效果不达标 | 中 | 高 | 早做 POC，对比 MinerU/Docling 效果 |
| 开源后竞争力被复制 | 低 | 中 | 核心差异在架构（多租户），而非单一功能 |
| 商业化节奏过早 | 中 | 中 | 先积累用户 + 口碑，再推付费 |
| 团队资源不足 | 高 | 高 | 聚焦核心差异功能，砍低优先级 |
| Dify 等竞品跟进多租户 | 中 | 中 | 持续创新，多在集成深度和企业安全下功夫 |
