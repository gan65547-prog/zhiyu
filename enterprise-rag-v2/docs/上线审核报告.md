## 三、P0 - 阻塞性问题（必须修复才能上线）

### 3.1 速率限制仅基于内存，多 Worker 下完全失效

- **文件**: `api/middleware/security.py:32-107`
- **问题**: `RateLimitMiddleware` 使用 `defaultdict(list)` 在进程内存中存储请求时间戳。当运行多个 Gunicorn worker 或 Uvicorn 多进程时，每个进程独立计数，实际限流能力 = `requests_per_minute × worker数`，形同虚设。
- **风险**: 恶意用户可通过并发请求绕过限流，导致 DoS。
- **修复方案**: 改用 Redis 实现分布式滑动窗口限流。

### 3.2 CSRF 保护对 API 路径实际关闭

- **文件**: `api/middleware/security.py:155-216`
- **问题**: `EXEMPT_PATHS` 包含 `/api` 前缀（第 165 行），导致所有 `/api/v1/*` 请求跳过 CSRF 检查。第 190 行直接 `return await call_next(request)` 忽略非安全方法。
- **风险**: CSRF 攻击者可通过表单提交等方式诱导用户执行非预期操作（如创建租户、修改配置）。
- **修复方案**: 移除 `/api` 豁免路径，对非安全方法实现完整 Token 验证。

### 3.3 缺少容器编排（Kubernetes）配置

- **问题**: 仅有 docker-compose 单机部署方案，无 K8s manifests / Helm chart。
- **风险**:
  - 无法水平扩展 Web/Worker
  - 无滚动更新、蓝绿部署
  - 无自动扩缩容
  - 无 Pod 级别健康检查和自愈
- **修复方案**: 编写 K8s 部署配置（Deployment / Service / HPA / ConfigMap / Secret）。

### 3.4 数据库连接池未针对生产调优

- **文件**: `core/config.py:35-38`
- **问题**: 默认 `pool_size=10, max_overflow=20`，Web 和 Worker 共用相同配置。未配置连接池监控和健康检测。
- **风险**: 突发流量可能导致连接池耗尽，请求排队超时。
- **修复方案**: 根据 Web/Worker 不同负载特征配置独立连接池参数，添加连接池指标监控。

### 3.5 关键依赖版本过旧且无漏洞扫描

- **文件**: `requirements/runtime.txt`
- **问题**:
  - FastAPI 0.104.1（当前 0.115+）
  - Pydantic 2.5.0（当前 2.10+）
  - `cryptography==41.0.7`（当前 44.0+，含多个 CVE 修复）
  - 无 `pip-audit` / Dependabot 等自动漏洞检测
- **风险**: 已知 CVE 可能被利用。
- **修复方案**: 升级关键依赖，集成 `pip-audit` 到 CI。

## 四、P1 - 高优先级

### 4.1 缺失 API 集成/E2E 测试
- 单元测试覆盖良好（554 个用例），但 CI 中无 API 集成测试和端到端测试
- 无前端测试
- **建议**: 为核心业务流程添加 API 集成测试；添加前端组件测试

### 4.2 SSL/TLS 未配置
- Nginx 只监听 80 端口，无 HTTPS
- 生产环境必须配置 SSL 证书和 301 重定向

### 4.3 生产文档 / API 文档缺失
- `debug=False` 时 OpenAPI 文档不可访问
- 无外部托管的 API 参考文档

### 4.4 CI 中未运行数据库迁移
- GitHub Actions CI 不执行 `alembic upgrade head`
- 迁移的幂等性和回滚未在 CI 中验证

### 4.5 优雅关闭未实现
- 无 SIGTERM 信号处理
- 应用关闭时未等待进行中的 Celery 任务和 DB 连接释放

### 4.6 CORS / 内部白名单生产环境需硬化
- `INTERNAL_IP_WHITELIST` 部署配置默认 `["*"]`
- CORS `allowed_origins` 默认仅包含 localhost，生产需配置真实域名

### 4.7 文件存储使用本地磁盘
- 上传文件存储在 `./runtime/uploads`，多实例无法共享
- 无文件备份策略
- **建议**: 引入 S3/MinIO 兼容的对象存储

## 五、P2 - 中优先级

- Prometheus 配置存在但无 Grafana 仪表板
- 无告警规则（AlertManager）

### 5.2 Celery 任务监控缺失
- 无 Flower 或其他 Celery 监控
- 部分任务缺少重试策略和死信处理

### 5.3 无功能开关系统
- JsonBodySecurityMiddleware 使用手动环境变量开关
- 缺少统一功能开关框架

### 5.4 备份恢复验证流程缺失
- 备份服务存在但无可执行的恢复测试脚本

### 5.5 日志管理分散
- Web 和 Worker 日志各自独立，无集中采集
